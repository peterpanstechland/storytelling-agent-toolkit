## 本项目的接入与核对

- DA3 Small：采用公开 Apache-2.0 权重，已在本机执行多视图推理；用实际图像特征逐帧核对三维/二维对应。当前网格来自参考视图的可见深度，其他关键帧预测保留在工程中。
- SAM 2.1 Tiny：已运行视频对象蒙版传播，目标表面与前景分别处理，保留异常区间记录。
- LaMa：本地参考帧修补；真实内部照片优先用于有实际参考的切开效果。生成补景记录为创意补全，不能称恢复真实内部。
- Blender 5.2.3：原生几何、源图材质、动画、环境碰撞代理、Cycles 环境阴影接收和可编辑工程；通过 CLI 调用。
- PyCOLMAP 4.0.3：已安装并核对 API，本轮尚未作为完整重建分支验收。
- 社区 [MCP for Blender](https://github.com/ahujasid/mcp-for-blender)：已查阅公开文档；尚未添加到用户的 MCP 连接，不声称原作者使用的就是这个实现。

源码、模型下载版本和内容校验记录在 `config/cg-upstreams.lock.json`。模型与第三方运行时保留在私有 `.runtime`，不混入可移植的 Skill 源码包。

验收以实际导出和各镜头 review 为准；相机重投影数值、模型加载成功和 CG 视觉完成度分别记录。树干自然生长、完整手部配饰跟踪、大幅绕拍和更复杂的碰撞仍需对应素材验证，不能从产品碎片短样推断已达标。
